# Mobile-Sales-Dashboard---PowerBi

latest project: The Mobile Sales Dashboard built in Power BI!Every great data visualization starts with a solid foundation. For this project, I took a raw, unstructured mobile sales dataset, cleaned and transformed it using Power Query, and built an interactive dashboard to uncover key business insights.📊 Key Dashboard Highlights:Geographical Insights: Visualized total sales performance across different cities using interactive map integration.   Trend Analysis: Tracked total quantities sold month-by-month and analyzed sales patterns by specific day names.   Customer Insights: Evaluated customer satisfaction levels using a structured funnel chart for ratings.   Payment Preferences: Broken down transaction distributions across multiple payment methods using a detailed pie chart.   Brand Performance: Summarized total sales and quantities across top mobile brands like Samsung, Apple, Vivo, Xiaomi, and OnePlus.
